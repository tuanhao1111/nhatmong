Copy toàn bộ đoạn dưới vào Firebase Console → Firestore Database → Rules → Publish:

════════════════════════════════════════
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
════════════════════════════════════════

Sau khi Publish xong, mọi trình duyệt đều đọc/ghi được.
