NHẤT MỘNG

Design tokens dựa trên Radix Colors + typography Linear-inspired. Theme tửu quán giang hồ — đỏ son, vàng đèn lồng, đồng cổ.

Color Scales · 12 steps mỗi scale

Click để copy hex code. Step 9-10 = solid, 11-12 = text, 1-2 = bg, 3-5 = component bg, 6-8 = border.

Typography

Playfair Display cho headings (display, editorial drama), Be Vietnam Pro cho body và UI (sans Vietnamese-first).

--fs-sm Caption nhỏ — meta info, helper text, secondary labels.
--fs-xs Tag · Label · Badge

Buttons

Tap target ≥ 40px (cozy) hoặc 44px (mobile min). Focus ring có viền đỏ son.

Form Inputs

Focus ring đỏ son APCA-compliant. Mobile font-size = 16px để iOS không zoom.

Cards · Stat Tiles · Empty State

Card hover có lift effect, stat tile cho dashboard KPIs, empty state cho session chưa có data.
